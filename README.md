# AntiAFK

Держит персонажа активным, чтобы не выкидывало за AFK.

Сделан под **Majestic RP** — работает с ним прямо сейчас. **GTA5RP** появится в 2.0.0, подробнее в [ROADMAP.md](ROADMAP.md).

## Скачать

Последний релиз лежит [здесь](https://github.com/BxdiS/antiafk/releases) — нужен только `AntiAFK.exe`.

Один файл, установка не нужна, права администратора тоже. Ничего не прописывается в систему: закрыл и удалил — как будто и не было.

Подписи у бинарника пока нет, поэтому при первом запуске Windows может показать предупреждение SmartScreen. Заявка в [SignPath Foundation](https://signpath.org/) в процессе — когда одобрят, релизы будут подписаны.

## Быстрый старт

Скачай, запусти, найди иконку в трее. Дальше **Запустить** — и можно уходить.

Цвет иконки говорит, что происходит:

| | |
|--|--|
| 🟢 | работает |
| 🟡 | ждёт, пока появится игра |
| 🔴 | остановлен |
| 🔵 | есть обновление |

В меню трея: настройки, живой лог, инфо о версии, кнопка обновления (если есть что обновлять) и выход.

## Что нужно

Windows 10 или 11, x64. 
Игра — в оконном режиме без рамки, разрешение 16:9. Другие пропорции пока не поддерживаются, это [в планах](ROADMAP.md).
