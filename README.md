# AntiAFK

**Бот для имитации активности, чтобы персонажа не кикало за AFK.**  

---

## 🚀 Скачать

**[Последний релиз](https://github.com/BxdiS/antiafk/releases)** — `AntiAFK.exe`

> **Портативный** · Без установки · Без прав администратора  
> **Один файл** (68 МБ)

### Подпись кода

*Бинарники готовятся к подписанию через [SignPath Foundation](https://signpath.org/).*  
*(Скоро: каждый релиз будет иметь цифровую подпись, проверяемую средствами Windows)*

---

## ⚡ Быстрый старт

1. **Скачай** `AntiAFK.exe` из [Releases](https://github.com/BxdiS/antiafk/releases)
2. **Запусти** — установка не нужна, права администратора не требуются
3. **Появится иконка в трее** → нажми **Запустить**, чтобы включить бота, и **Остановить**, чтобы поставить на паузу

| Иконка | Статус |
|--------|--------|
| 🟢 | Работает |
| 🟡 | Ожидание игры |
| 🔴 | Остановлен |
| 🔵 | Доступно обновление |

**Меню трея:** Настройки · Консоль логов · О программе · Обновить (при наличии) · Выход

---

## 📋 Требования

- **Windows 10/11** x64
- **Окно игры:** Оконный режим без рамки, разрешение 16:9
