## Зачем

Majestic RP кидает проверку на АФК, и если её не пройти — вылет из игры. AntiAFK сидит в трее, сам замечает окно игры и проходит проверку за тебя: ферма, ночная смена, любой отход от компьютера переживаются без потери сессии.

Сделан под **Majestic RP** — работает с ним прямо сейчас. **GTA5RP** появится в 2.0.0, подробнее в [ROADMAP.md](ROADMAP.md).

## Что внутри

- **Один файл.** Установки нет, прав администратора нет, в реестр и автозагрузку ничего не пишется. Удалил `.exe` — как будто и не было.
- **Само поднимается.** Игра не запущена — ждёт; появилась — начинает работать.
- **Автообновление.** Новая версия ставится из трея в один клик.
- **Живой лог.** Видно, что именно программа делает прямо сейчас.
- **Два языка.** Русский и английский интерфейс.
- **Никакой телеметрии.** Ничего никуда не отправляется, исходники открыты целиком.

## Скачать

Последний релиз лежит [здесь](https://github.com/BxdiS/antiafk/releases/latest) — нужен только `AntiAFK.exe`.

Подписи у бинарника пока нет, поэтому при первом запуске Windows может показать предупреждение SmartScreen: **Подробнее → Выполнить в любом случае**. Заявка в [SignPath Foundation](https://signpath.org/) в процессе — когда одобрят, релизы будут подписаны.

## Быстрый старт

Скачай, запусти, найди иконку в трее. Дальше **Запустить** — и можно уходить.

Цвет иконки говорит, что происходит:

| | |
|--|--|
| 🟢 | работает |
| 🟡 | ждёт, пока появится игра |
| 🔴 | остановлен |
| 🔵 | есть обновление |

В меню трея: настройки, живой лог, инфо о версии, кнопка обновления (если есть что обновлять) и выход.

## Что нужно

Windows 10 или 11, x64.
Игра — в оконном режиме без рамки, разрешение 16:9. Другие пропорции пока не поддерживаются, это [в планах](ROADMAP.md).
Масштабирование дисплея — 100%: координаты кликов считаются в реальных пикселях, при другом масштабе они разъезжаются.

## Как это устроено

C# и .NET 8, интерфейс на WinForms, весь код — в этом репозитории. Программа не лезет в память игры и ничего в неё не внедряет: она находит окно, поднимает его и отправляет обычные клики и нажатия через Windows API — ровно то же, что делают мышь и клавиатура. Между действиями стоят задержки, чтобы ввод выглядел человеческим, а не серией мгновенных событий.

Собрать из исходников можно самому — как, написано в [docs/GUIDE.md](docs/GUIDE.md). Там же настройки, автообновление и история с подписью кода.

## Частые вопросы

**Это чит?** Нет. Игровые файлы и память не трогаются, читерских возможностей не добавляется — программа просто нажимает кнопки вместо тебя.

**А забанят?** Гарантий не даёт никто: правила сервера — на стороне сервера, и решение об использовании ты принимаешь сам. Никакой защиты от обнаружения тут нет и не планируется.

**Antivirus/SmartScreen ругается.** Бинарник пока не подписан — см. раздел [Скачать](#скачать). Исходники открыты, сборку можно сделать свою.

**Работает с другими серверами?** Пока нет. Координаты и логика написаны под Majestic RP; GTA5RP и профили серверов — [в роадмапе](ROADMAP.md).
