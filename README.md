# AntiAFK

**Бот для предотвращения AFK на маркетплейсе GTA V multiplayer.**  
Держит персонажа активным, чтобы не отключили за неактивность.

---

## 🚀 Скачать

**[Последний релиз](https://github.com/BxdiS/antiafk/releases)** — `AntiAFK.exe`

> **Портативный** · Без установки · Без прав администратора  
> **Один файл** (68 МБ) · Всё включено

## ⚡ Быстрый старт

1. **Скачай** `AntiAFK.exe` из [Releases](https://github.com/BxdiS/antiafk/releases)
2. **Запусти** — Установка не нужна, прав администратора не нужно
3. **Иконка в трее** → Нажми **Запустить** чтобы начать, **Остановить** чтобы пауза

| Иконка | Статус |
|--------|--------|
| 🟢 | Работает |
| 🟡 | Ожидание игры |
| 🔴 | Остановлен |
| 🔵 | Доступно обновление |

**Меню трея:** Настройки · Консоль логов · О программе · Обновить (при наличии) · Выход

---

## 📋 Требования

- **Windows 10/11** x64
- **Окно игры:** Оконный режим без рамки, разрешение 16:9
