# AntiAFK

Держит персонажа активным, чтобы не выкидывало за AFK.

Сделан под **Majestic RP** — работает с ним прямо сейчас. **GTA5RP** появится в 2.0.0, подробнее в [ROADMAP.md](ROADMAP.md).

## Скачать

Последний релиз лежит [здесь](https://github.com/BxdiS/antiafk/releases) — нужен только `AntiAFK.exe`.

Один файл, установка не нужна, права администратора тоже. Ничего не прописывается в систему: закрыл и удалил — как будто и не было.

Подписи у бинарника пока нет, поэтому при первом запуске Windows может показать предупреждение SmartScreen. Заявка в [SignPath Foundation](https://signpath.org/) в процессе — когда одобрят, релизы будут подписаны. Подробности ниже, в разделе [Code signing policy](#code-signing-policy).

## Быстрый старт

Скачай, запусти, найди иконку в трее. Дальше **Запустить** — и можно уходить.

Цвет иконки говорит, что происходит:

| | |
|--|--|
| 🟢 | работает |
| 🟡 | ждёт, пока появится игра |
| 🔴 | остановлен |
| 🔵 | есть обновление |

В меню трея: настройки, живой лог, инфо о версии, кнопка обновления (если есть что обновлять) и выход.

## Что нужно

Windows 10 или 11, x64. 
Игра — в оконном режиме без рамки, разрешение 16:9. Другие пропорции пока не поддерживаются, это [в планах](ROADMAP.md).
Масштабирование дисплея — 100%: координаты кликов считаются в реальных пикселях, при другом масштабе они разъезжаются.

## Code signing policy

Политика подписи кода.

Free code signing provided by [SignPath.io](https://about.signpath.io/), certificate by [SignPath Foundation](https://signpath.org/).

Релизы пока не подписаны. Заявка на рассмотрении, и до её одобрения SmartScreen продолжит ругаться на первый запуск.

### Роли

Мейнтейнер один, и все три роли на нём — автор, ревьюер, аппрувер: [BxdiS](https://github.com/BxdiS).

Всё попадает в `main` через pull request, а не прямым пушем, включая правки самого мейнтейнера. Как это устроено — в [CONTRIBUTING.md](CONTRIBUTING.md).

### Политика приватности

У AntiAFK нет аналитики, нет отправки отчётов о падениях и нет аккаунтов. Программа ничего не собирает и никуда ничего от твоего имени не отправляет.

Наружу уходит один запрос — проверка, не вышла ли новая версия:

- `https://api.github.com/repos/BxdiS/antiafk/releases/latest`, один раз при старте и дальше каждые 6 часов.
- HTTPS GET с user agent `antiafk-updater`. Ни идентификаторов, ни данных о машине, ничего про игру и/или аккаунт.
- Если версия новее есть, `AntiAFK.exe` и его `.sha256` качаются во временную папку, и контрольная сумма проверяется. Файл, не прошедший проверку, удаляется.
- Установка — подмена экзешника и перезапуск — происходит только по клику «Обновить» в меню трея.

В меню трея переключателя для неё нет. Помогает блокировка `api.github.com` на файрволе: ошибка уходит в лог, приложение работает дальше.
